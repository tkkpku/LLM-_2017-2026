# 大语言模型发展综述（2017-2026）

面向本科生的入门读物，梳理 2017 到 2026 年大语言模型的技术演进、产业格局与学术前沿。正文约 18 万字，14 章，参考文献 120 余篇。数据截止 2026 年 7 月。

读者需具备基础编程与数学知识。
